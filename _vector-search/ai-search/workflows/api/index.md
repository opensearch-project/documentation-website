# Workflow APIs

OpenSearch supports the following workflow APIs:

* [Create or update workflow]({{site.url}}{{site.baseurl}}/vector-search/ai-search/workflows/api/create-workflow/)
* [Get workflow]({{site.url}}{{site.baseurl}}/vector-search/ai-search/workflows/api/get-workflow/)
* [Provision workflow]({{site.url}}{{site.baseurl}}/vector-search/ai-search/workflows/api/provision-workflow/)
* [Get workflow status]({{site.url}}{{site.baseurl}}/vector-search/ai-search/workflows/api/get-workflow-status/)
* [Get workflow steps]({{site.url}}{{site.baseurl}}/vector-search/ai-search/workflows/api/get-workflow-steps/)
* [Search workflow]({{site.url}}{{site.baseurl}}/vector-search/ai-search/workflows/api/search-workflow/)
* [Search workflow state]({{site.url}}{{site.baseurl}}/vector-search/ai-search/workflows/api/search-workflow-state/)
* [Deprovision workflow]({{site.url}}{{site.baseurl}}/vector-search/ai-search/workflows/api/deprovision-workflow/)
* [Delete workflow]({{site.url}}{{site.baseurl}}/vector-search/ai-search/workflows/api/delete-workflow/)

For information about workflow access control, see [Workflow template security]({{site.url}}{{site.baseurl}}/vector-search/ai-search/workflows/workflow-security/).

# Action Group APIs

The Action Group APIs create, retrieve, modify, and delete action groups, which are reusable collections of permissions.

| API | Method | Endpoint |
| :--- | :--- | :--- |
| [Get Action Group API]({{site.url}}{{site.baseurl}}/security/api/action-groups/get-action-group/) | GET | `/_plugins/_security/api/actiongroups/{action_group}` |
| [Get Action Groups API]({{site.url}}{{site.baseurl}}/security/api/action-groups/get-action-groups/) | GET | `/_plugins/_security/api/actiongroups` |
| [Create Action Group API]({{site.url}}{{site.baseurl}}/security/api/action-groups/create-action-group/) | PUT | `/_plugins/_security/api/actiongroups/{action_group}` |
| [Patch Action Group API]({{site.url}}{{site.baseurl}}/security/api/action-groups/patch-action-group/) | PATCH | `/_plugins/_security/api/actiongroups/{action_group}` |
| [Patch Action Groups API]({{site.url}}{{site.baseurl}}/security/api/action-groups/patch-action-groups/) | PATCH | `/_plugins/_security/api/actiongroups` |
| [Delete Action Group API]({{site.url}}{{site.baseurl}}/security/api/action-groups/delete-action-group/) | DELETE | `/_plugins/_security/api/actiongroups/{action_group}` |

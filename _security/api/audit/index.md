# Audit Log APIs

The Audit Log APIs retrieve and modify the audit logging configuration.

| API | Method | Endpoint |
| :--- | :--- | :--- |
| [Get Audit Configuration API]({{site.url}}{{site.baseurl}}/security/api/audit/get-audit-configuration/) | GET | `/_plugins/_security/api/audit` |
| [Update Audit Configuration API]({{site.url}}{{site.baseurl}}/security/api/audit/update-audit-configuration/) | PUT | `/_plugins/_security/api/audit/config` |
| [Patch Audit Configuration API]({{site.url}}{{site.baseurl}}/security/api/audit/patch-audit-configuration/) | PATCH | `/_plugins/_security/api/audit` |

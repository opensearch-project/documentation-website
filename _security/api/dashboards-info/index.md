# Dashboards Info APIs

The Dashboards Info APIs return the Security plugin settings that OpenSearch Dashboards needs in order to render its interface.

| API | Method | Endpoint |
| :--- | :--- | :--- |
| [Get Dashboards Info API]({{site.url}}{{site.baseurl}}/security/api/dashboards-info/get-dashboards-info/) | GET | `/_plugins/_security/dashboardsinfo` |
| [Post Dashboards Info API]({{site.url}}{{site.baseurl}}/security/api/dashboards-info/post-dashboards-info/) | POST | `/_plugins/_security/dashboardsinfo` |

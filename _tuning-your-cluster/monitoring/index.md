# Monitoring your cluster

OpenSearch can record metrics and traces about its own operation and export them using OpenTelemetry. For more information, see [Telemetry]({{site.url}}{{site.baseurl}}/tuning-your-cluster/monitoring/telemetry/index/).

To find the slowest and most resource-intensive queries running in your cluster, see [Query insights]({{site.url}}{{site.baseurl}}/tuning-your-cluster/monitoring/query-insights/index/).
